## Бэклог
- Сборщики wohnnet.at, immowelt.at, derstandard.at/immobilien, ЖК-сайты (Danube Flats, «Adele» Bloch-Bauer-Promenade 16), heute.at.
- Официальный список myflexbox.
- Поднять потолок сборщика аренды выше 2 200 € (вопрос пользователю).
- Скорость продажи по району (дни до снятия), индекс снижения цен, история медиан по времени (снимки district_stats раз в неделю → таблица).
- Заправки как минус-фильтр, зоны для собак, зелень.
- Сравнение двух домов бок о бок.

## Продукт (после личного MVP)
- Брендинг, упаковка, лендинг; веб + PWA/приложение.
- Мульти-пользователи (сейчас белый список двоих), тарифы, онбординг (свои точки, требования).
- B2B: API/отчёты для маклеров (справедливая цена, скорость продажи, конкуренты-новостройки), алерты.
- Юридическое: условия источников (Willhaben/ImmoScout ToS), атрибуции ODbL/CC-BY, хранение только ссылок на чужие фото.
