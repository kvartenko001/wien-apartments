# 15. Доступ для других людей (этап 1)

## Модель
- **Рабочее пространство (ws).** У каждого участника своё. `main` — общее у Павла и Ариши.
- **Общее для всех:** лента (market_listings), радар, слои карты, оценка места, ставки, **каталог домов** (buildings — проверенные данные о доме).
- **Личное (по ws):** список своих домов `ws_buildings` (статус, приоритет, заметки), подборки `building_collections`, избранное ленты `market_favorites`, свои точки `poi`, `ratings`, `visits`.
- **Личное (по почте):** `user_settings` — фильтры, требования, слои, лента. Синхронизируются каждые 20 с и при закрытии страницы; на новом устройстве подтягиваются.
- Дом, который уже есть в каталоге (в радиусе 25 м, внутри контура, по адресу или алиасу), при добавлении **не разбирается заново** — просто попадает в список человека.

## Доступ и безопасность
- `members`: email, ws, role (`admin`/`user`), active, paid_until, max_devices, note, last_seen.
- `private.me()` — участник активен и срок не истёк. На нём построены `is_member()`, `my_ws()`, `is_admin()` и все правила RLS.
- Каталог `buildings` и `listings` видны только для домов из своего списка (админ видит всё). Писать в каталог может только админ и функции (add_building — security definer).
- Проверено 19.11.2026 под тремя почтами: Павел 24 дома, Ариша 24, новый участник 0 домов / 0 точек / 0 подборок, но 33 531 объявление в ленте и 521 проект радара. Новый участник, добавивший Arsenalstraße 12, получил уже разобранный Parkapartments.

## Лимит устройств
`session_check()` при входе и раз в 10 минут: оставляет `max_devices` самых новых сессий, остальные удаляет. Старое устройство выкидывается с сообщением «вошли на другом устройстве». Отключённый или просроченный участник выкидывается с сообщением «нет доступа».

## Вход
Почта + пароль (выдаёт админ) или ссылка на почту. Встроенная почта Supabase отправляет очень мало писем — поэтому основной путь — пароль. Для продукта нужен свой SMTP.

## Админка (👑 в шапке, только role = admin)
- «Выдать доступ»: почта, имя, оплачено до, устройств, заметка, «общая база со мной». Если логина не было — создаётся и показывается пароль + готовое сообщение для отправки.
- По каждому: статус, срок, устройства, последний заход, его дома, «что ищет» (фильтры), кнопки +30 дней / +1 год / выключить / новый пароль / лимит устройств.
- Edge function `admin` (проверяет role = admin), SQL: `admin_overview()`, `admin_upsert_member()`.
