## Модель данных (03_radar.sql)
- `developers` — реестр: тип (commercial / nonprofit / municipal / broker / area), размер (large/mid/small), сайт (+ подтверждён ли), страница проектов, сегменты, районы, slug на wiew.at.
- `dev_projects` (расширена) — проект: источник и slug, застройщики, адрес/координаты, сегмент, квартир всего/в продаже/в резерве, диапазоны м²/цен/€/м² и медиана, год сдачи, энергокласс, удобства, связь с нашим `buildings`, first/last_seen/removed_at.
- `dev_units` — **каждая квартира проекта** с историей цены, `reserved_at`, `gone_at` (исчезла из списка ⇒ вероятно продана).
- `dev_projects_stats` — `sold_30d`, `reserved_30d`, `units_repriced`, `premium_vs_district_pct` (медиана €/м² проекта к медиане продажи района).

## Метрики радара
- **Скорость продаж** = квартир ушло (gone + новые резервы) за 30 дней; **месяцев до распродажи** = в продаже / скорость.
- **Премия новостройки** = (медиана €/м² проекта / медиана продажи района − 1) × 100%.
- **Давление на цену** = доля квартир проекта со снижением цены; сигнал торга.
- **Катализатор**: расстояние до будущих станций U5/U2 (`data/planned.json`); проекты ≤ 800 м — отдельная метка.
- **Застройщик**: число проектов, медиана €/м², доля распроданного, средняя скорость.

## Тип проекта (с 13.11.2026, вечер)
Пользователь заметил: Steudelgasse 21-23 (дом 1900 г., санирован 2022) показывался как «новостройка». Теперь у каждого проекта `project_type`:
| Тип | Что это | Как определяем (текст wiew.at: название, описание, подзаголовок, «Highlights») |
|---|---|---|
| `neubau` — Новостройка | дом с нуля (пустой участок или на месте снесённого) | всё, что не попало в другие типы |
| `dachausbau` — Мансарды / надстройка | новые квартиры на крыше старого дома | признаки старого дома + Dachgeschoss/DG-Ausbau/Aufstockung |
| `umbau` — Перестройка | офис/склад/отель → жильё | Umnutzung, «ehemaliges Bürogebäude» и т.п. |
| `altbau` — Санированный альтбау | старый дом отремонтирован целиком | «Fertigstellung 1900 (renovated 2022)», Altbau, Zinshaus, Gründerzeit, Jahrhundertwende, «aus dem Jahre 1885» |
Плюс `built_year` (год постройки дома) и `renovated_year` (год санации). Для альтбау `completion_year` = год санации (иначе дом 1900 г. красился бы как «уже сдан»).
На карте: новостройка — закрашенная точка, остальные типы — кольцо цвета года. По умолчанию в фильтре включены только новостройки.
Проверка на 16 проектах: Steudelgasse → altbau (1900/2022), Krongasse 6 → altbau (1885), Redtenbachergasse 43 → dachausbau, Augasse 17 → neubau.

## Фото проектов (mode=photos)
1. wiew.at — `image[]` из JSON-LD проекта (визуализации, в полном размере).
2. Официальный сайт (`official_url`) — все `<img>/<source>` (берём самый крупный вариант из srcset), `background-image`, og:image; подписи `alt`.
3. С официальной страницы — до 3 ссылок «Baufortschritt / Baustelle / Bautagebuch / Webcam / Galerie / Bilder / Impressionen» того же сайта. Всё с таких страниц = фото стройки.
- Тип снимка: `outside` (снаружи), `inside` (Innen, Wohnzimmer, Küche…), `build` (Baustelle, Rohbau, Gleichenfeier, Spatenstich…), `plan` (Grundriss, графики, таймлайны — не показываем).
- Дата фото стройки: из подписи / имени файла / текста рядом («Oktober 2026», «15.09.2026», «2026-09»). Сортировка стройки — новые сверху.
- Мусор отсекается: логотипы, иконки, портреты сотрудников, партнёры, соцсети; блоки «weitere Projekte» (картинки других проектов); новостные разделы не обходим.
- Дубли одного снимка в разных размерах склеиваются по имени файла.
- Обновление: cron `radar-photos` каждые 3 мин по 12 проектов, пока не пройдены все; потом каждый проект раз в 7 дней (фото стройки меняются помесячно).
- Честно: фото стройки публикует меньшинство застройщиков (в выборке 30 проектов 2026–27 явных галерей стройки почти нет), визуализации есть почти у всех.
- Планировки квартир: `dev_units.plan_url` из JSON-LD каждой квартиры, кнопка ⌗ в таблице квартир.
