# 06 · Интерфейс (index.html + app.js + style.css)

Без сборщиков и фреймворков: один HTML, один JS (~1 300 строк), один CSS. Mapbox GL JS v3 + supabase-js с CDN.
Версия файлов — `?v=<timestamp>` в ссылках, меняется при каждом деплое (иначе браузер держит старое).

## Экран
- **Карта** на весь экран (Mapbox Standard, 3D-здания, три темы: графит / синяя ночь / монохром; кнопка темы).
- **Шторка слева** (на телефоне — снизу, тянется за «ручку») с вкладками:
  - **Дома**: переключатель «Наши дома / Лента / ★ Избранное».
    - Наши дома: очередь разбора, «＋ Добавить дом» (название ЖК / адрес / клик по карте → подтверждение «Это тот дом?» → `add_building`), список карточек (цена «от», район, год, высота, число объявлений; не проходящие требования — тусклые с причиной).
    - Лента: «↻ Обновить» (до 8 районов), кнопка фильтров с числом активных, сортировка (новые / дешёвые / за м² / выгоднее района), карточки объявлений, «ещё 60».
    - Избранное: объявления со ★.
  - **Требования**: потолок, база (грязная/полная), комнаты, м², amenities, районы, статусы, «скрыть не проходящие».
  - **Слои**: транспорт (U, S, трам, автобус; значки/точки; названия станций), строящиеся линии, районы, POI Mapbox, шум (4 источника × день/ночь, легенда),
    «Рядом с домом» (супермаркеты + бренды, аптеки, дежурные аптеки, почта, боксы + бренды, солнце), объявления на карте, 3D.
  - **Расчёт**: покупка (взнос, ставка, срок) и аренда (срок контракта, обустройство, возврат мебели).
- **Переключатель «Аренда / Покупка»** вверху: меняет ленту (загружается `deal_type` режима), фильтры (хранятся отдельно), карточки, расчёты.
- **Карточка дома справа** (`#detail`): название, адрес, статус, галерея фото, факты с источниками, amenities, заметки, карусель объявлений (`.lscroll`),
  раздел «Шум» (сворачивается), раздел «Дорога» (свёрнут по умолчанию): точки он/Ариша/зал/центр/свой адрес, варианты, «на машине».
- **Панель фильтров ленты справа** (`#feedPanel`): цена от/до + пресеты (аренда 1000–2000; покупка 300k–700k), м², комнаты, районы, источник,
  только новые (2 дня), цена снижалась, частник, наши дома, лифт упомянут, дешевле медианы района, (покупка) только новостройки; «Как в требованиях», «Сбросить».
- **Просмотр объявления справа** (`#lview`): фото, заголовок, факты, оснащение, описание, контакт; кнопки на сайты, «На карте», «Открыть дом» / «＋ Отслеживать этот дом»;
  в покупке — блок «сколько это стоит на самом деле».

## Модули app.js (по разделам)
темы → состояние `S` → карта (слои: транспорт, районы, дома-контуры `fp-*`, свечение, рынок `mk-dot`, OSM `osm-*`, солнце `sun-*`, шум WMS, маршруты) →
данные (`buildings_map`, `listings`, `poi_map`, `transit_lines_v2`) → фильтры/`evaluate` → список → выбор дома (подлёт `flyTo`, дом в центре свободной части экрана) →
дорога (`fetchRoute`, `fetchCar`, `drawTrip`) → шум (`loadNoise`) → добавить дом → рынок (`loadMarket` постранично по 1 000, `groupMarket`, `feedCard`, `passFF`) →
покупка (`vsDistrict`, `buyCalc`, `annuity`, `buyBlock`) → просмотр объявления (`openListing`, `trackHouse`) → рядом с домом (`loadOsm`, `pushOsm`) → солнце → кнопки → камера → шторка/вкладки/режим → слои → расчёт → вход (magic link).

## Состояние и хранение
- `S.mode` rent/buy, `S.f` требования, `S.c` расчёт, `S.ff` фильтры ленты, `S.market`/`S.mkGroups`, `S.favs`, `S.stats` (медианы), `S.osm`, `S.selected`.
- localStorage (префикс `wa_`): `theme`, `layers`, `ff` (фильтры аренды), `ffBuy` (фильтры покупки), `shopBrands`, `lockBrands`, `sec_<noise|route>`, `c_eq`, `c_rate`, `c_years`.
- sessionStorage: кэш маршрутов `wa_r2_*`.
