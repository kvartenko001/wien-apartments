# Wien — квартиры

Инструмент для поиска, анализа и покупки/аренды жилья в Вене: 3D-карта Mapbox, весь рынок Willhaben + ImmoScout24 каждый день,
реальная стоимость, честность цены, шум, дорога, «рядом с домом». Пока личный, задуман как будущий продукт.

**Полная документация — [`docs/`](docs/README.md).** Бэкенд (SQL, edge-функции) — [`supabase/`](supabase).

- Карта: Mapbox Standard, темы «графит», «ночь», «монохром»
- Данные: Supabase, доступ только для участников
- Маршруты транспорта: © участники OpenStreetMap (ODbL)
- Шумовые карты 2022: BMK / Umweltbundesamt (laerminfo.at)
- Маршрутизация: Wiener Linien OGD (CC BY 4.0)
- Районы: Statistik Austria / Flooh Perlot (CC BY 4.0)
