# Оценка локации — методика (черновик, 14.11.2026)

Ожидает подтверждения миграции `location_score` в Supabase.

## Компоненты и веса («Общий» профиль)
| Компонент | Вес | Как считается |
|---|---|---|
| Транспорт | 25 % | 65 % — ближайшая U-Bahn (100 % до 400 м пешком, 0 % от 1 200 м) или S-Bahn (×0,85); 35 % — трамвай/автобус: число остановок в 400 м (4 = максимум) или ближайшая остановка (200→600 м) |
| Каждый день | 20 % | супермаркет 40 % (300→1 000 м), аптека 20 % (400→1 200), Hausarzt 25 % (400→1 200), почта 15 % (500→1 500) |
| Дети | 15 % | детсад 35 % (300→1 000), школа 35 % (500→1 500), площадка 30 % (200→800) |
| Зелень | 15 % | край парка ≥ 0,5 га 60 % (200→800), большой массив ≥ 10 га 40 % (500→2 000) |
| Спорт и больница | 5 % | спортплощадка 25 %, фитнес 25 %, бассейн 20 % (1→3 км), больница 30 % (1,5→5 км) |
| Тишина | 10 % | Lden у самого громкого фасада: 100 при ≤ 50 дБ, 0 при ≥ 75 дБ |
| Климат | 10 % | жара у дома к медиане Вены: 100 при ≤ −3 °C, 0 при ≥ +4 °C |

Пешее расстояние = прямое × 1,25 (извилистость сети). Пороги: 400 м ≈ 5 минут пешком, 1 200 м ≈ 15 минут («город 15 минут»).
Профиль «Пара без детей»: вес «Дети» = 0, остальные пропорционально.
Процентиль: каждая часть сравнивается с ~10 000 реальных адресов объявлений рынка Вены (без точек-«центроидов»).
